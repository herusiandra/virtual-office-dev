# PLAYBOOK: DOKUMENTASI APLIKASI YANG SUDAH JADI

Tujuan: dokumen yang akurat, berbukti, dan berguna bagi pembacanya (ditentukan brief: pengguna akhir, developer, atau operasional).

| Fase | Pelaku | Hasil |
|---|---|---|
| F0 Kerangka | Heru + Naufal | daftar bagian dokumen, pembaca sasaran, format keluaran |
| **Gate A** | Pengguna | persetujuan kerangka |
| F1 Investigasi | Naufal (mode dokumentasi) | fakta berbukti per bagian: fitur, alur, data, antarmuka, konfigurasi |
| F2 Dukungan teknis | Rajif | menjawab pertanyaan Naufal tentang kode; menyusun bagian teknis/diagram bila diminta Heru |
| F3 Katalog layar | Priyo (bila ada UI) | daftar layar dan state, dari bukti Naufal |
| F4 Penulisan | Naufal | draf dokumen merujuk bukti |
| F5 Verifikasi | Denis | menguji akurasi dokumen terhadap aplikasi (cuplikan acak + semua bagian kritis); temuan ke Naufal |
| F6 Perbaikan | Naufal ⇄ Denis | maks. 3 putaran |
| F7 Serah | Heru → pengguna | paket dokumen final + daftar hal tak terverifikasi |

Dokumentasi hanya menyatakan yang terverifikasi; sisanya ditandai.
